# retirement-planning-simulator
A Python Monte Carlo simulation modeling retirement savings under uncertain investment returns and inflation.

* Simulates investment returns using probability distributions
* Accounts for annual inflation and inflation volatility
* Runs multiple simulations to estimate potential retirement balances
* Visualizes projected balances using histograms and growth charts

* Uses Python, NumPy, and Matplotlib

Disclaimer: This project is an educational simulator and does not provide financial advice.
